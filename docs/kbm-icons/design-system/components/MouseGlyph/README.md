A mouse button or movement, drawn as a 20×27 mouse with the pressed zone filled black.

Provide the asset from the Mouse group: `<img class="xp-mouse" src="…" alt="Left mouse button">`. Always give `alt` text.

- RT is the left button and LT is the right button (XCL crosses them so fire stays on the left click).
- RB is wheel up and LB is wheel down; each notch is one press.
- Use the move glyph for the right stick (camera).
